# WikiArticleFeeds

A MediaWiki extension that publishes RSS or Atom feeds generated from
ordinary wiki pages.

Wikimedia archived this extension in 2023
(https://phabricator.wikimedia.org/T333512). WikiEducator
maintains it here, with one branch per MediaWiki release:

* `REL1_35` - version 2.0.0 for MediaWiki 1.35
* `REL1_23` - 0.71 with item-tags security fix

Older branches are unchanged upstream code.

    git clone -b REL1_35 https://github.com/WikiEducator/WikiArticleFeeds.git
